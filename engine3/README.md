# engine3

De nieuwe rekenkern van Brew Console, in voorbereiding. Uitleg, contract, datamodel, migratie,
technieken, meetopstelling en open punten staan in [docs/engine3/](../docs/engine3/README.md).

- `src/`: contract (types), eenheden, logboek, migratie, data (technieken, regeltabel, smaakwiel)
- `eval/`: meetopstelling (virtuele Jelle, maatstaven, Engine 2 als nulmeting)
- `test/`: node:test + fast-check (`npm run e3:test`)
